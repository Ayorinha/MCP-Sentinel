# Security Policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities through public Issues. Report them privately through the contact method published by the project maintainer.

Include a clear description, affected component, reproduction steps, impact, and relevant evidence.

Never include secrets, credentials, personal data, or production tokens in Issues, Pull Requests, examples, tests, or logs.

## Responsible disclosure

Please allow reasonable time for investigation and remediation before public disclosure. Security fixes should include regression coverage whenever practical.
