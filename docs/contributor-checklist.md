# Contributor Checklist

Before opening a pull request:

- [ ] Keep the change focused and minimal.
- [ ] Add or update tests for changed behavior.
- [ ] Run the project's local validation when available.
- [ ] Document security-relevant behavior and assumptions.
- [ ] Keep secrets, credentials, and private data out of commits.
- [ ] Explain validation results in the pull request.

Security-related reports should follow the repository security policy.
